# Golden Tradition — локальная копия

- Сайт: http://localhost:8080/
- Админка: http://localhost:8080/wp-admin/
- WordPress: 7.1.3 (PHP 8.3), MariaDB: 10.11.
- Рабочие файлы сайта: `site/`. Здесь новое ядро WordPress и перенесённый `wp-content`.
- Исходные файлы `joy.mk.ua` также сохранены в корне этой папки для сравнения.
- Дамп базы: `database/234.sql`. Он уже импортирован в Docker volume `goldentradition_db_data`.
- URL старого сайта в локальной базе заменены на `http://localhost:8080` (кроме поля `guid`).
- Администратор из исходной базы: `nover`. Пароль не изменялся.

Запуск из этой папки: `docker compose up -d`.
Остановка без удаления данных: `docker compose down`.
Проверка: `docker compose ps`.

Тема и большинство старых плагинов скопированы как есть. Responsive Lightbox обновлён с 1.6.7 до 2.7.11.1: старая версия открывала чёрный экран поверх мобильного меню. Перед обновлением остальных плагинов стоит проверить страницы и формы.
Не используйте `docker compose down -v`, если хотите сохранить уже импортированную базу.
